# 🐍 贪吃蛇 Pro

一款精美的贪吃蛇网页游戏，支持 **12 个独特皮肤**，适配手机和桌面浏览器。

## 🎮 在线游玩

👉 [点击这里开始游戏](https://godcorn.github.io/snake_game_github/)

## ✨ 特色功能

| 功能 | 说明 |
|------|------|
| 🎨 **12 个皮肤** | 默认、钢铁侠、修罗铠甲、刑天铠甲、帝皇铠甲、彩虹、霓虹、冰霜、火焰、暗黑、像素、金色 |
| 📱 **手机适配** | 滑动控制 + 虚拟按键 |
| ⭐ **特殊食物** | 金色星星 +50 分 |
| 📊 **本地排行** | 最高分自动保存 |
| ⌨️ **键盘控制** | 方向键 / WASD / P 暂停 |

## 🎨 皮肤预览

- 🟢 **默认** - 经典绿色渐变
- 🔴 **钢铁侠** - 红金配色
- ⚫ **修罗铠甲** - 暗红脉冲效果
- 🔵 **刑天铠甲** - 蓝银配色
- 🟣 **帝皇铠甲** - 紫金彩虹渐变
- 🌈 **彩虹** - 流动彩虹色
- 💜 **霓虹** - 赛博朋克闪烁
- 🧊 **冰霜** - 蓝白闪烁光泽
- 🔥 **火焰** - 红橙火焰效果
- 🖤 **暗黑** - 暗紫呼吸脉冲
- 💚 **像素** - 复古像素风
- 🟡 **金色** - 金属闪烁光泽

## 🕹️ 操作说明

- **电脑**: 方向键 / WASD 控制方向，P 暂停
- **手机**: 滑动屏幕 或 点击虚拟按钮控制方向
- 吃到红色食物 +10 分，吃到金色星星 +50 分
- 随着分数增加，速度会逐渐加快

## 📦 部署方式

本游戏是纯 HTML/CSS/JavaScript，无需任何依赖，直接用浏览器打开 `index.html` 即可游玩。
